Privacy Policy (promotionTool Ads)

Effective date: November 17, 2026

promotionTool Ads ("the App") is an internal tool used solely by its operator to analyze the operator's own Amazon Ads account. The App is not offered to any third party.

1. Information we collect

Through the Amazon Ads API, the App retrieves campaign settings and performance data (such as impressions, clicks, spend, and sales) of the operator's own advertising account. The App does not collect any personal information about Amazon customers.

2. How we use information

The data is used only to create suggestions for improving the operator's advertising settings (bids, budgets, keywords). Any change to the advertising account is decided and made by the operator.

3. Storage and sharing

The data is stored only on devices and servers managed by the operator. It is never sold to or shared with third parties.

4. Deletion

When the connection to the Amazon Ads API is revoked, the data retrieved through it will be deleted.

5. Contact

Please contact us via GitHub Issues of this page's repository.

プライバシーポリシー（promotionTool Ads）

制定日: 2026年11月17日

promotionTool Ads（以下「本アプリ」）は、運営者が自社の Amazon 広告アカウントを分析するためだけに使う社内ツールです。第三者には提供しません。

1. 取得する情報

Amazon Ads API を通じて、運営者自身の広告アカウントのキャンペーン設定と実績（表示回数・クリック数・費用・売上など）を取得します。Amazon の購入者の個人情報は取得しません。

2. 利用目的

広告の設定（入札額・予算・キーワード）の見直し案を作るためだけに使います。広告アカウントの変更は、運営者が判断して行います。

3. 保管と第三者提供

取得したデータは、運営者が管理する端末とサーバーにのみ保管します。第三者に販売・提供することはありません。

4. 削除

Amazon Ads API との連携を解除したときは、連携で取得したデータを削除します。

5. お問い合わせ

お問い合わせは、このページのリポジトリの GitHub Issues からお願いします。
